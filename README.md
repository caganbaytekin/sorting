# Python Programming Basics

This repository contains simple Python programs for learning basic algorithms and data structures.

## Programs

- **Quick Sort** – Sorting elements using the divide-and-conquer method.
- **Insertion Sort** – Sorting elements by inserting them into the correct position.
- **Linear Search** – Searching for an element one by one.
- **Binary Search** – Searching efficiently in a sorted list.
- **Count Occurrences** – Counting how many times an element appears in a list.
- **Input Validation** – Handling invalid user input using exception handling.
- **LIFO (Stack)** – Last In, First Out data structure.
- **FIFO (Queue)** – First In, First Out data structure.

## Technologies Used

- Python 3
